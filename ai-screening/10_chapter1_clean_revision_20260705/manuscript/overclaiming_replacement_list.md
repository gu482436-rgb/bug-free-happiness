# Targeted Overclaiming Replacements

Use these replacements when updating the HTML report or manuscript text.

| Avoid | Replace with |
|---|---|
| safe peptide | peptide with computational low-risk predictions |
| confirmed non-toxic | predicted Non-Toxin by ToxinPred |
| confirmed non-allergenic | AllerCatPro returned "no evidence"; experimental allergenicity testing is still required |
| safety_pass | computational low-risk flag |
| all safety predictions passed | all computational low-risk/no-evidence filters were passed |
| good VP1 docking support | relatively favorable computational VP1 docking score |
| docking supports binding | docking suggests a possible pose; experimental binding validation is required |
| food-system safety | suitability for food-system testing remains to be experimentally evaluated |
| validated antiviral peptide | candidate antiviral peptide |
| proven anti-norovirus activity | predicted AVP-like features; anti-norovirus activity requires MNV or NoV-VLP validation |
| P2 mechanism confirmed | P2 contact was observed in a computational model and requires experimental validation |
| optimized mutation | model-generated mutation hypothesis |
